 STEP 1: FIREBASE — Create Project & Get API Keys
================================================================================

1.1  Go to: https://console.firebase.google.com/
1.2  Click "Add project" → Name it "AI-Fitness-Form-Analyzer"
1.3  Disable Google Analytics (not needed for free tier) → Click "Create project"
1.4  Wait for project to be created, then click "Continue"

--- Enable Email/Password Auth ---
1.5  In left sidebar, click "Build" → "Authentication"
1.6  Click "Get started"
1.7  Click "Email/Password" → Toggle ENABLE → Click "Save"

--- Enable Google Sign-In ---
1.8  Go back to "Authentication" → "Sign-in method" tab
1.9  Click "Google" → Toggle ENABLE
1.10 Enter your email as "Project support email"
1.11 Click "Save"

--- Enable Firestore Database ---
1.12 In left sidebar, click "Build" → "Firestore Database"
1.13 Click "Create database"
1.14 Select "Start in test mode" → Click "Next"
1.15 Choose any location (e.g., us-central1) → Click "Enable"

--- Create Firestore Index (REQUIRED for queries) ---
1.16 In Firestore, go to the "Indexes" tab
1.17 Click "Add Index" (Composite Index)
1.18 Create these indexes:
     Collection: "sessions"  |  Fields: userId (Asc), timestamp (Desc)  |  Query Scope: Collection
     Collection: "sessions"  |  Fields: userId (Asc), timestamp (Asc)   |  Query Scope: Collection
     Collection: "users"     |  Fields: totalReps (Desc)                |  Query Scope: Collection
     NOTE: If the indexes are auto-created when you first use the app (you'll see error links
     in browser console), just click those links and it will create them for you automatically.

--- Get Firebase Config Keys ---
1.19 Click the gear icon (⚙) next to "Project Overview" → "Project settings"
1.20 Scroll down to "Your apps" section
1.21 Click the Web icon ( </> )
1.22 Register app with nickname: "fitness-frontend"
1.23 You will see a `firebaseConfig` object. COPY these values:
     - apiKey
     - authDomain
     - projectId
     - storageBucket
     - messagingSenderId
     - appId

     ✅ SAVE THESE — you will need them in Steps 5 and 6.

 STEP 4: RENDER — Deploy Backend (Python/FastAPI)
================================================================================

4.1  Go to: https://render.com/ and sign up for FREE (use GitHub login)
4.2  Click "New +" → "Web Service"
4.3  Connect your GitHub account if not already connected
4.4  Select the repository you created in Step 3
4.5  Configure the service:
     - Name: ai-fitness-backend
     - Region: Oregon (or any close to you)
     - Branch: main
     - Root Directory: backend          ← IMPORTANT: type "backend"
     - Runtime: Python 3
     - Build Command: pip install -r requirements.txt
     - Start Command: gunicorn main:app --workers 1 --worker-class uvicorn.workers.UvicornWorker --bind 0.0.0.0:$PORT --timeout 120
     - Instance Type: FREE

4.6  Click "Advanced" → "Add Environment Variable" and add these:

     Key: FRONTEND_URL            Value: (leave blank for now, fill after Step 5)
     Key: CLOUDINARY_CLOUD_NAME   Value: (from Step 2.3)
     Key: CLOUDINARY_API_KEY      Value: (from Step 2.3)
     Key: CLOUDINARY_API_SECRET   Value: (from Step 2.3)
     Key: PYTHON_VERSION          Value: 3.10.0

4.7  Click "Create Web Service"
4.8  Wait for the build & deploy (takes 3-5 minutes)
4.9  Once deployed, your backend URL will be shown at the top, like:
     https://ai-fitness-backend.onrender.com

     ✅ COPY THIS URL — you need it for Steps 5 and 6.

4.10 Test it: Open that URL in your browser. You should see:
     {"status":"ok","message":"AI Fitness Form Analyzer Backend is running."}

 STEP 6: UPTIMEROBOT — Keep Backend Alive (Prevent Render Sleep)
================================================================================

Render free tier puts your backend to sleep after 15 minutes of no requests.
UptimeRobot will ping it every 5 minutes to keep it alive FOR FREE.

6.1  Go to: https://uptimerobot.com/ and create a FREE account
6.2  Click "Add New Monitor"
6.3  Configure:
     - Monitor Type: HTTP(s)
     - Friendly Name: AI Fitness Backend
     - URL: https://ai-fitness-backend.onrender.com/health
           (use YOUR actual Render URL from Step 4.9, add /health at the end)
     - Monitoring Interval: 5 minutes
6.4  Click "Create Monitor"

     ✅ Done! Your backend will now stay alive 24/7.

================================================================================
 STEP 7: FIREBASE SECURITY RULES (Important Before Sharing)
================================================================================

When your project is working and you're ready to submit/share it:

7.1  Go to Firebase Console → Firestore Database → "Rules" tab
7.2  Replace the existing rules with:

     rules_version = '2';
     service cloud.firestore {
       match /databases/{database}/documents {

         // Users can read/write their own profile
         match /users/{userId} {
           allow read: if true;
           allow write: if request.auth != null && request.auth.uid == userId;
         }

         // Sessions: users can create their own, anyone can read
         match /sessions/{sessionId} {
           allow read: if true;
           allow create: if request.auth != null
                         && request.resource.data.userId == request.auth.uid;
           allow update, delete: if false;
         }
       }
     }

7.3  Click "Publish"
